# 手持 MID360 动态物体过滤 Goal

建立日期：2026-10-03。状态：active，研究和实现阶段。

## 固定基线

- 仓库：`Silentbarber/yhbuildmap_ws`。
- 开发分支：`feature/dynamic-object-filtering`。
- baseline 提交：`9a11f2ec19575c6b6ca2f8abf99abb0f5452e82e`。
- baseline 版本：`handheld-mid360-2026-10-03`。
- baseline 算法：ROS1 Faster-LIO + `observation_geometry` 离线后端。
- 保留 baseline 代码、四张 PCD、轨迹和逐帧缓存；开发不覆盖它们。

## 目标

在用户已认可的建图结果上，减少四个包中运动物体形成的点云残留，同时保护建筑静态结构、细小物体和只被扫描一次的区域。交付可复现的 ROS1 工程集成、四个包各自的过滤 PCD、独立三维查看入口、参数和验证报告。

第一阶段使用相同的优化后轨迹评估地图过滤。只有得到可靠对照后，才评估动态点是否需要反馈到前端匹配或后端约束构建。离线地图清理与在线动态检测分别记录，不能将离线结果描述为实时能力。

| 方法 | 官方来源与固定提交 | 适合研究的方向 | 此任务需要验证的适配点 |

| Removert | [gisbi-kim/removert](https://github.com/gisbi-kim/removert/tree/7e76d892af2fb09f79da75a6e0a2380e74506586) | 现有扫描与轨迹的离线静态地图构建；Remove-then-Revert 机制 | 距离图分辨率、垂直视场、非重复扫描、手持转动、批次边界和薄结构恢复；不可直接使用 KITTI/Ouster 默认配置 |

已检查的 Removert 提交中，根目录未列出许可证文件，`package.xml` 的 license 字段为 `TODO`，因此目前仅作为方法研究候选，尚未将其代码引入本仓库。进一步核查源码声明后再决定代码复用方式。

## 实现约束

1. 区分观测到的表面、射线穿过的自由空间、被遮挡区域和没有测量的区域。MID360 空像素或没有再次命中不自动构成动态证据。
2. 将位姿残差、测量噪声、角度栅格误差纳入判断余量；检查墙面边缘、玻璃、门框、柱子、地面和楼梯的误删。
3. 不依据类别名称直接删除所有人形或小物体；主要目标是有运动/占据变化证据的残留。长期静止物体和只观察一次的区域保留不确定性。
4. 多帧证据需考虑相邻帧相关性，不把同一次经过的高频采样当成大量独立确认。
5. 保留原强度值和源帧索引，能够审计被删点属于哪些时间段及使用了哪些证据。输出保留点、移除点和未确定点的统计；不通过任意空间裁剪美化结果。
6. 首次比较固定轨迹与地图体素尺寸，不以更粗的下采样冒充动态过滤收益。
7. 流式读取现有缓存，控制内存和磁盘成本；当前磁盘可用约 2.2 GiB，避免保存重复的整套逐帧 PCD。
8. 新开关默认可回退到 baseline；实验失败不覆盖已验收地图。

## 验证与交付

- 四包均使用相同主流程和明确记录的参数；场景专用参数必须说明依据。
- 对运动残留明显的区域做时间分层和多角度检查，同时检查固定静态墙面与薄结构。
- 保留同坐标系 baseline / filtered / removed 三种视图，每次独立显示一张地图。
- 记录动态残留变化和静态结构误删。没有人工确认标签时，指标只称为内部一致性或删除统计，不能称为动态检测精确率/召回率。
- 记录全部帧覆盖、地图点数、过滤前后静态几何一致性、耗时、峰值内存和新增磁盘占用。
- 针对静态墙、移动遮挡、稀疏缺测、遮挡后墙面、薄结构及位姿小误差设置有意义的回归检查。
- 交付四张过滤后的 PCD、四个独立三维入口、移除点可视化、运行命令、源代码与报告。
- 用户肉眼验收后才标记选定版本；不保证未经验证场景下零残留或零误删。
